# Shuai Wu · 武帅

I study how soil microbial communities change with depth and climate in drylands and permafrost regions. I combine field sampling with reanalysis of public amplicon and metagenomic data, keeping the links between physical samples, sequencing libraries and environmental records explicit.

## 中文简介

我研究干旱区与永久冻土区的土壤微生物生态，关注同一剖面中的群落如何随深度变化，以及这些规律能否在不同气候和土壤条件下复现。我整理全球公开测序数据，并在分析中保留物理样品、土层、文库和环境记录之间的对应关系。
