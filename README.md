# Shuai Wu · 武帅

I’m interested in how biodiversity varies across space and time, how ecological communities assemble, and how ecosystems respond to environmental change. One question that connects these interests is why similar environments can support very different communities.

I bring field observations, environmental measurements and public datasets together to ask which patterns hold across sites and which depend on local conditions. I also build reusable R and Python workflows for comparing communities, modeling ecological responses and synthesizing evidence across studies.

| [Soil amplicon workflows with DADA2](https://github.com/azaleawu/soil-amplicon-dada2) | Process soil 16S, ITS and 18S reads, choose marker-specific settings, and assess which libraries can be compared across studies. |
| [Permafrost metagenomics](https://github.com/azaleawu/oligarchy-permafrost-microbiomes) | Follow a genome-resolved workflow from assembly and abundance profiling to phylogenetic and environmental analyses of permafrost microbiomes. |

The toolkit and the DADA2 workflow connect through a public Atacama Desert example. The DADA2 workflow produces a count table from five soil libraries. The toolkit uses that table to calculate diversity and compare the samples. I curated the catalogue and wrote the examples around tools developed by the linked software teams. [From reads to ASVs](https://github.com/azaleawu/soil-amplicon-dada2/blob/main/docs/soil-example.md) · [From ASVs to community summaries](https://github.com/azaleawu/ecology-analysis-toolkit/tree/main/data)

## 中文简介

我关注生物多样性在时间和空间上的变化、群落的形成，以及生态系统如何响应环境变化。一个贯穿这些方向的问题是：为什么环境相似的地方，有时会形成截然不同的生物群落？

我把野外观测、环境测量与公开数据结合起来，比较哪些规律在不同地点依然成立，哪些取决于当地条件。我也在整理可复用的 R 和 Python 工作流，用于群落比较、生态响应建模和跨研究证据综合。这里展示的土壤微生物、冻土宏基因组和生态分析工具库，是其中几个例子。
